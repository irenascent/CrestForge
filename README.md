CrestForge enables real-time data processing across distributed systems, utilizing an auto-scaling orchestrator and dynamic scheduler for optimized performance.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/CrestForge.git`
2. `cd CrestForge`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
